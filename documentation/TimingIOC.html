Injection Sequence State Notation Language Program

Timing Records

Record names are prefixed with "$(T)".  For production the $(T) macro value is empty.

Name
 Type
 Description
TimPotentate
 bi
 Enable/disable injection cycles.  The event generator INJ:injCycleEnable record is set to zero when this record is zero or when the sequence program is unable to connect to all PVs.
TimInjReq
 waveform
 Seven integer values describing the injection cycle parameters.  A new value must be received by the start of each injection cycle or a default injection cycle will be generated.
GunBunchToInjFieldTrigger
 waveform
 Integer values indexed by one less than the number of bunches contained in the current TimInjReq.  The selected value is used to modify the delays for the gun on and gun off events.
TimAllEVRvalid
 calc
 Value is 1 when all event receivers are reporting valid input links and 0 otherwise.  A non-default injection cycle will be requested only when all event receiver input links are valid.
InjSeqDebug
 longout
 Sets level of timing sequence program diagnostic messages.
InjSeqSuccessCount
 longout
 Incremented for each injection cycle successfully requested.
InjSeqFailedCount
 longout
 Incremented for each injection cycle that was unable to be requested.
InjSeqFaultCode
 mbbo
 Status of most recent injection cycle request.
InjSeqStartOverrunCount
 longout
 Incremented each time that a TimInjReq was received too late to request an injection cycle.


Event Generator Records

The timing state notation language program interacts with the event generator through the following records.

$(P)$(R)E1:seqStatus
$(P)$(R)E1:seqStarts
$(P)$(R)INJ:injCycleEnable
$(P)$(R)E1:SEQ1
$(P)$(R)E1:SEQ1:enable

Other Records

The timing state notation language program monitors the beam current "SR:DCCT:AVG" record.
